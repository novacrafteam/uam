# UAM — Ukraine Analytic Map

Файли сайту:
- `index.html` — сам сайт (карта, пошук, вимірювання, мови, календар змін)
- `history/` — архів карти по днях (наповнюється автоматично)
- `scripts/snapshot.py` та `.github/workflows/snapshot.yml` — автоматика, яка кожні 3 години
  зберігає знімок карти, якщо в ній щось змінилось

Як підключити (GitHub Pages, безкоштовно):
1. Створи репозиторій на github.com (наприклад `uam`) і завантаж у нього ВСІ файли з цієї папки,
   зберігши структуру папок.
2. Settings → Pages → Branch: `main`, папка `/ (root)` → Save. Сайт з'явиться за адресою
   `https://ТВІЙ_НІК.github.io/uam/`.
3. Вкладка Actions → «Save map snapshot» → Run workflow (перший запуск вручну). Далі працює сама.
4. Карта в Google Мої карти має бути відкрита для перегляду за посиланням.
